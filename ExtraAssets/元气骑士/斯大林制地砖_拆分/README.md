# 斯大林制地砖：按元素拆分

原图：336×224，RGBA 透明 PNG。共导出 150 个裁片。

- 01_floor：47 个地板/地形裁片，主要为 16×16；岩浆边缘延伸至 17×17，保留实际像素。
- 02_walls：26 个墙/石块裁片，16×24、16×25、16×28 等不同尺寸。
- 03_props：57 个场景物件裁片，包括箱桶、树木、矿车、火盆、设备、雕像、仙人掌、地毯等。
- 04_traps：8 个箭头、陷阱裁片。
- 06_swatches：12 个原图色板裁片，单独归类，不当作游戏物件。

## 拆分方式

按视觉语义与实际布局指定不同尺寸的区域，然后裁去外围完全透明的空白；祭坛与音响旁混入的相邻素材像素按归属排除，原像素仍保留在其所属裁片中。未缩放、未重绘、未改色，保留半透明像素。16 像素是主要横向间距，不是全图通用的切片尺寸。

树根、轨道、设备侧边、地毯流苏等超出格子的像素均予保留。南瓜与周围蜡烛、两座相连石像、带灯冰岩等相接组合保留整体，不强行抹除共享边缘。原图中的叠放箱子和上下堆叠箭头也保持其完整组合。因此 150 是裁片数量，并非 150 种互不重复的独立物体。

## 文件

- preview.png：全部元素及像素尺寸总览，棋盘格仅用于显示透明背景。
- preview_props.png：大物件和陷阱的局部预览。
- source_regions.png：原图上的编号与裁切边界。
- index.csv：可用 Excel 打开的尺寸、坐标与文件索引。
- manifest.json：源图哈希、区域与裁片边界（左上角坐标；右/下边界不包含）。
- 上一级 split_stalin_tiles.py：可重复运行的拆分脚本，依赖 Pillow。

## 验证

所有导出的非透明像素均与原图对应像素一致；按原坐标合并非透明像素后，重建图与原图 RGBA 字节完全一致，未遗漏任何像素。未修改源图、未导入 Unity Assets。
