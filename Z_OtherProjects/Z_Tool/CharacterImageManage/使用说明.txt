人物素材对齐工具

安装 Python 3 和 Pillow（python -m pip install Pillow）。双击“对齐人物素材.bat”后输入标准 PNG 图片路径，也可以把标准图片拖到 bat 上。

程序读取标准图片的上方和下方连续空行，以其为基准处理 bat 所在目录下的所有 PNG 图片（不是参考图所在目录）；不按文件名或方向筛选，递归扫描所有子目录。标准图片本身不会修改。

判定空行时，只有透明度大于或等于 128 的像素才视为内容。程序等比缩放图片并上下平移，使内容上下边界与标准图一致（允许 1 像素误差），保持画布尺寸和水平居中，直接覆盖成功处理的图片。内容为空、会裁切透明度大于或等于 128 的像素或对齐误差超过 1 像素的图片会跳过并报告；已对齐的图片不会改写。运行前建议自行备份素材。

也可通过命令行运行：python align_character.py "标准图片.png"

参考图可以放在任意目录，仅读取标准；待处理目录以 bat 自身的位置为准，与启动时的工作目录无关。直接运行 Python 时默认处理脚本所在目录，也可用 --directory 指定。

仅对齐下方透明行：运行“对齐下方透明行.bat”，输入参考 PNG 或将其拖到 bat。只处理 bat 所在目录的 PNG（包含所有子目录），跳过参考图本身。按透明度 >=128 确定内容底部，仅做整数像素上下平移，不缩放、不左右移动，保持各图画布尺寸；下方透明行已相同的图片不改写。若平移会裁切透明度 >=128 的内容则跳过；透明度 <128 的画布外像素可能被裁掉。成功处理会覆盖原图，建议先备份。允许参考图和待处理图画布尺寸不同，尺寸不同时先在内存中将参考图整体缩放到每张待处理图的宽高，再计算下方透明行数。

参考图尺寸适配（两个 bat 均适用）：参考图与目标 PNG 尺寸不一致时，先将参考图整个画布（含透明边距）在内存中缩放到当前目标图的宽高，再以透明度 >=128 重新计算对齐标准。每张目标图分别计算；不修改参考文件，不改变目标图的画布尺寸。宽高比分别适配目标尺寸，不做裁切或补边。

递归扫描说明：三个 BAT 都处理自身所在目录及其所有子文件夹，跳过 .resize-backups、.tool-backups、__pycache__、符号链接及目录联接，不跟随链接到其他目录。对齐工具仍仅处理 PNG，并跳过标准图本身；缩放工具保持原有格式范围。缩放备份按相对目录保留，子文件夹中同名图片不会互相覆盖。日志显示相对路径。配套 image_files.py 须与三个 Python 脚本放在一起。
