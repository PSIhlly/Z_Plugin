PNG 平均切图工具
================

1. 把需要裁剪的 PNG 放到“切图.bat”和 split_png.py 所在目录。
2. 双击“切图.bat”，先输入行数，再输入列数，均为正整数。
3. 本目录下每张 PNG 都会生成“行数×列数”张切片，子目录不会被扫描。
4. 结果保存到 output 下，每张原图单独一个目录。例如输入 a.png，2 行 3 列：
   output/a_2x3/r01_c01.png ～ r02_c03.png
   行从上往下，列从左往右，编号均从 1 开始。

原图保持不变；重复运行会另建 a_2x3_2 等目录，保留旧结果。
保留原像素、颜色模式和透明背景，不缩放图片。
宽高不能整除时，以整数比例分界均摊余数，切片宽高最多相差 1 像素；不会丢掉右边或下边的像素。
行数不能超过图片像素高度，列数不能超过图片像素宽度；不满足的图片会单独报告失败，继续处理其他图片。
支持 .png / .PNG；若输入动画 PNG，仅裁剪第一帧。

环境：Python 3 + Pillow。bat 会尝试 python、py -3，以及当前 Codex 自带的 Python。
找不到可用环境时，安装 Python，然后执行：python -m pip install Pillow

也可在命令行运行：
python split_png.py 2 3
python split_png.py 2 3 --directory "D:\需要切图的目录"

可把“切图.bat”和 split_png.py 一起复制到其他图片目录使用。
